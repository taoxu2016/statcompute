# Issues found in the packages this project reads

Decision D-12 (the maintainer's, 2026-11-20): pprof_py is the statistical specification, not unquestionable
computational ground truth; statcompute validates independently and reports what it finds, and a change of
methodology is reviewed explicitly. This register is where a finding waits until it is reported, and where the
answer is kept. Nothing here changes a package: every remedy is a suggestion for its maintainers.

An entry needs evidence that someone else can run. "Reported" is set only when the maintainers have been told;
"answered" when they have replied, with what they decided.
